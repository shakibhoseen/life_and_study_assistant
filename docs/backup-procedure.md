# ব্যাকআপ ও ফিরিয়ে আনা

অ্যাপের সব ডেটা একটি JSON ফাইলে রাখা যায়, আর সেই ফাইল থেকেই আবার ফেরানো যায়।

---

## কোথায় রাখা হয়

```
/storage/emulated/0/Download/LifeAndStudyAssistant/
```

ফোনের **Files → Downloads → LifeAndStudyAssistant** ফোল্ডারে পাবেন। দু'রকম ফাইল থাকে:

| নাম | কে বানায় | কবে মুছে যায় |
|---|---|---|
| `auto_backup_২০২৬-১১-১০_০৯৩০.json` | অ্যাপ নিজে | শেষ ৭টির বাইরেরগুলো |
| `life_study_backup_….json` | আপনি, Settings থেকে | **কখনো না** |

> ফোল্ডারটা না পেলে Settings → ব্যাকআপ কার্ডে আসল পথটা লেখা থাকে। কিছু ফোনে Download-এ লেখা আটকানো থাকলে অ্যাপ নিজের ফোল্ডারে রাখে, আর সেই পথটাই দেখায়।

---

## ১. স্বয়ংক্রিয় ব্যাকআপ (কিছু করতে হয় না)

অ্যাপ খুললেই, **দিনে একবার**, নিজে থেকে একটা ফাইল লেখা হয়। শেষ **৭টি** রাখা হয়, পুরোনোগুলো নিজে থেকেই মুছে যায়। আপনার নিজের হাতে নেওয়া ব্যাকআপে হাত পড়ে না।

Settings-এর ব্যাকআপ কার্ডের উপরে লেখা থাকে **সর্বশেষ কবে হয়েছে**। ওখানে তারিখ না বদলালে বুঝবেন কিছু একটা আটকে আছে।

---

## ২. নিজে ব্যাকআপ নেওয়া

**Settings → Offline Data Backup & Restore → ব্যাকআপ**

বড় কিছু করার আগে — অ্যাপ আপডেট, ফোন বদল, অনেক প্রশ্ন স্ক্যান করার পর — এটা একবার চালিয়ে ফাইলটা অন্য কোথাও (Drive, নিজের মেইল, কম্পিউটার) রেখে দিন।

---

## ৩. ফিরিয়ে আনা

**Settings → Offline Data Backup & Restore → রিস্টোর** → ফাইল বেছে নিন।

ফেরানোর পর কী কী ফিরল তার হিসাব দেখানো হয়। একই ফাইল দু'বার রিস্টোর করলে কিছু দ্বিগুণ হয় না — প্রতিটা সারি কী, সেটা দেখে মেলানো হয়।

---

## ফাইলে কী কী থাকে

- দুর্বল টপিক
- পরীক্ষার শিডিউল
- দৈনিক এনার্জি লগ
- **স্মার্ট মিস্টেক নোটবুকের সব প্রশ্ন**
- ড্রিলের ইতিহাস (heatmap এটা থেকেই আঁকা)
- রিভিশন কার্ডের শিডিউল
- সেটিংস টেবিল
- ফোনের preferences — কোন model, scanner-এর পছন্দ, আজকের টিক দেওয়া task

## যা **থাকে না**

- **API key।** ব্যাকআপ ফাইল Downloads-এ থাকে, মেইল হয়, কম্পিউটারে কপি হয় — সেখানে প্লেইন টেক্সটে key রাখা মানে key ফাঁস। রিস্টোরের পর একবার বসিয়ে নিতে হবে। রিস্টোর কখনো নতুন বসানো key মুছে পুরোনোটা বসায় না।
- বুদবুদের খসড়া লেখা — গতকালের আধখানা বাক্য আজ ফিরিয়ে লাভ নেই।
- AI-এর cache। ওটা আবার তৈরি হয়ে যায়, আর ফাইলটা অকারণে ভারী করত।

## অ্যাপ আবার install করার আগে

`flutter install` বা নতুন APK বসানোর সময় signature না মিললে Android **পুরোনোটা uninstall করে দেয়, আর তাতে সব ডেটা মুছে যায়**। তাই:

1. আগে Settings থেকে একটা ব্যাকআপ নিন
2. ফাইলটা Downloads থেকে অন্য কোথাও সরিয়ে রাখুন (uninstall-এ Downloads মুছে না গেলেও, ফোন বদলালে যাবে)
3. তারপর install করুন
4. নতুন অ্যাপে রিস্টোর করুন, আর API key বসিয়ে নিন

## Android-এর সংস্করণ নিয়ে

Android 11 (API 30) থেকে অ্যাপের পক্ষে পাবলিক ফোল্ডারে লেখা কঠিন করা হয়েছে। এই অ্যাপ তিনটে ধাপে চেষ্টা করে:

1. `Download/LifeAndStudyAssistant/` — সবচেয়ে ভালো, সবাই খুঁজে পায়
2. না পারলে অ্যাপের নিজের external ফোল্ডার
3. তাও না পারলে অ্যাপের ভিতরের ফোল্ডার, আর তখন ফাইল পিকার দিয়ে নিজে জায়গা বেছে নেওয়ার সুযোগ

Android 13-এ (যেটা এখন ব্যবহার হচ্ছে) প্রথমটাই কাজ করে — মেপে দেখা হয়েছে। ভবিষ্যতে কোনো সংস্করণে আটকে গেলে অ্যাপ নিজে থেকে পরের ধাপে যাবে এবং আসল পথটা দেখাবে, চুপ করে থাকবে না।

**Windows নিয়ে:** এখনকার কোডে desktop-এর জন্য `Downloads/LifeAndStudyAssistant/` ব্যবহার হয়, তাই Windows অ্যাপ বানালে একই ফাইল একই নিয়মে কাজ করবে। আলাদা কিছু লিখতে হবে না।
