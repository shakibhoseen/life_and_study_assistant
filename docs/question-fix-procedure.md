# প্রশ্ন সংশোধনের পদ্ধতি

ভুল প্রশ্ন ঠিক করার তিনটে রাস্তা আছে। তিনটেতেই শেষ সিদ্ধান্ত আপনার — অ্যাপ নিজে থেকে কিছু সেভ করে না, প্রতিটা পরিবর্তন আগে তালিকা হয়ে দেখানো হয়, আপনি টিক দিয়ে তবেই বসে।

---

## রাস্তা ১ — বাইরের AI দিয়ে (ChatGPT, Claude)

অনেক প্রশ্ন একসাথে যাচাই করার জন্য।

1. **স্মার্ট মিস্টেক নোটবুক** → উপরের **কপি** বাটন।
   প্রশ্নগুলোর সাথে নির্দেশনাও কপি হয় — ওটা মুছবেন না, ওটাই উত্তরের গঠন ঠিক করে দেয়।
2. ChatGPT বা Claude-এ **পুরোটা** পেস্ট করুন।
3. উত্তর আসবে একটা JSON array হিসেবে। **পুরোটা কপি করুন।**
4. নোটবুকে ফিরে **AI ফিক্স** → বাক্সে পেস্ট → **বিশ্লেষণ**।
5. তালিকা দেখে যেগুলো রাখবেন টিক রেখে **সেভ**।

ধাপ ৪-এ model লাগে না, খরচও নেই — উত্তরটা ঠিক গঠনে এলে ফোনেই পড়া হয়।

### বাইরের AI কী ফেরত দেয়

প্রতিটা সমস্যাযুক্ত প্রশ্নের জন্য একটা করে entry, `question_id` = প্রশ্নের পাশে `[Q-…]`-এ লেখা সংখ্যা:

```json
[
  {
    "question_id": 180,
    "status": "ambiguous",
    "proposed_correct_index": -1,
    "new_question_text": "",
    "new_options": [],
    "new_explanation": "",
    "is_delete": false,
    "reason": "খ ও গ অপশন দুটির অর্থ একই"
  }
]
```

চারটে `status`:

| status | মানে | উত্তরে প্রভাব |
|---|---|---|
| `incorrect` | নিশ্চিত ভুল | উত্তর বদলাতে পারে |
| `ambiguous` | একাধিক উত্তর সম্ভব | **উত্তর বদলায় না**, সতর্কতা বসে |
| `needs_source` | উৎস ছাড়া নিশ্চিত নয় | **উত্তর বদলায় না**, সতর্কতা বসে |
| `duplicate` | একই প্রশ্ন আরেকবার আছে | **উত্তর বদলায় না**, সতর্কতা বসে |

শেষ তিনটেতে বাইরের AI option বলে দিলেও অ্যাপ সেটা মানে না। সন্দেহ প্রমাণ নয়।

### কপি করার সময় যা হতে পারে

ChatGPT-র কোড ব্লক থেকে কপি করলে মাঝেমধ্যে প্রতিটি লাইনের শেষে `\` আর ফাঁকা জায়গায় `&#x20;` ঢুকে যায়। উত্তরটা ঠিকই থাকে, কিন্তু ওটা আর JSON থাকে না। অ্যাপ এখন ওগুলো নিজেই ছেঁটে নেয়, তাই পেস্ট করলেই চলবে।

### ভুল নম্বর দিলে কী হয়

প্রতিটি entry-তে `question_snippet` — প্রশ্নের প্রথম কয়েকটা শব্দ — চাওয়া হয়। অ্যাপ সেটা মিলিয়ে দেখে। না মিললে ওই সংশোধনটা **বাদ যায়**, অন্য প্রশ্নে বসে না।

এটা কল্পনা নয়: একবার ২১টা entry-র একটায় `[Q-101]`-এর বদলে সিরিয়াল `53` লেখা হয়েছিল, আর Q-53 হলো গারো নৃত্যের প্রশ্ন। snippet না থাকলে ইন্টারনেটের জনকের ব্যাখ্যাটা গারো নৃত্যের প্রশ্নে বসে যেত।

### অপশন বদলালে উত্তর কোথায় যাবে

`new_options` দিলে `proposed_correct_index`-ও দেওয়া ভালো। না দিলে অ্যাপ পুরোনো উত্তরের **লেখাটা** নতুন তালিকায় খুঁজে নেয়। শুধু একটা অপশন বদলালে উত্তর নিজের জায়গাতেই থাকে। আর পুরো তালিকা বদলে গিয়ে উত্তরের লেখাটা হারিয়ে গেলে অপশন বদলানোই হয় না — কারণ তখন সংখ্যাটা যেখানে দেখাচ্ছে, সেটা আর উত্তর নয়।

### উত্তর বর্ণনায় এলে

তাতেও চলে, তবে তখন প্রশ্নগুলো আর বর্ণনাটা Gemini-তে পাঠিয়ে গঠনে আনা হয় — key লাগে, নেট লাগে, token খরচ হয়। JSON-এ এলে কিছুই লাগে না।

## রাস্তা ২ — নিজে জানেন, মুখে বা টাইপ করে বলুন

বই পড়ে নিশ্চিত হয়েছেন — এটাই সবচেয়ে ভরসার রাস্তা, আর এতে কোনো AI লাগে না।

**AI ফিক্স** বাক্সে টাইপ করুন বা মাইক চেপে বলুন:

| যা বলবেন | যা হবে |
|---|---|
| `উত্তর গ হবে` | সঠিক উত্তর বদলায় |
| `অপশন খ হবে: তঞ্চঙ্গ্যা` | শুধু ওই অপশনটা বদলায়, বাকিগুলো থাকে |
| `প্রশ্ন হবে: …` | প্রশ্নের লেখাটাই বদলায় — যা বলবেন হুবহু তাই |
| `ব্যাখ্যা হবে: …` | উত্তর ঠিক রেখে শুধু ব্যাখ্যা বদলায় |
| `এই প্রশ্নে ভুল আছে` | উত্তর না বদলে সতর্কতা বসে |
| `বই দেখে নিতে হবে` | "উৎস যাচাই দরকার" সতর্কতা বসে |
| `প্রশ্নটা বাদ দাও` | প্রশ্নটি মোছার প্রস্তাব আসে |

### হুবহু বলতে হবে না

উপরের লেখাগুলো উদাহরণ, নির্দেশ নয়। কথাটা **কোন বিষয়ে** — উত্তর, অপশন, প্রশ্ন, না ব্যাখ্যা — সেটুকু বোঝা গেলেই হয়। শব্দের ক্রম, "টা/টি/তে/এর", "হবে/করুন/বসাও/লিখুন" — এসব যেভাবে খুশি:

- `অপশন গ হবে তঞ্চঙ্গ্যা`
- `গ অপশনটা তঞ্চঙ্গ্যা হবে`
- `অপশন গ তে তঞ্চঙ্গ্যা বসাও`
- `option c should be তঞ্চঙ্গ্যা`

— চারটেই এক জিনিস। অপশন `ক খ গ ঘ`-এর বদলে `১ ২ ৩ ৪`, `a b c d`, বা `তিন নম্বরটা`ও চলে।

**আরও সহজ করতে চাইলে ট্যাগ:** বাক্সের উপরে ছ'টা চিপ আছে — *সঠিক উত্তর*, *অপশন ঠিক করুন*, *প্রশ্নের লেখা*, *ব্যাখ্যা*, *সন্দেহ আছে*, *উৎস দেখতে হবে*। চাপ দিলে শুরুটা বাক্সে বসে যায়, তারপর শুধু কথাটুকু বলুন বা লিখুন। তখন আর অনুমানের জায়গাই থাকে না।

**আর শেষ রক্ষাকবচ:** যা বোঝা গেছে সেটা সেভের আগে তালিকায় দেখানো হয় — পুরোনো লেখা আর নতুন লেখা পাশাপাশি। ভুল বুঝলে টিক তুলে দিন।

### কোন প্রশ্ন, সেটা বলার নিয়ম

- **একটামাত্র প্রশ্ন সামনে থাকলে** নম্বর বলার দরকার নেই।
- **তালিকা থাকলে** শুরুতে বলুন `প্রশ্ন ৩ এর …`, অথবা পাশে লেখা আইডি ধরে `প্রশ্ন ১৮০ এর …`।
- নম্বর না বললে কোন প্রশ্ন বোঝা যায় না, তাই **কিছুই বসে না** — ভুল সারিতে বসানোর চেয়ে কিছু না বসানো ভালো।

### একসাথে কয়েকটা জিনিস

আলাদা লাইনে বললে একটাই সম্পাদনা হয়:

```
অপশন গ হবে: তঞ্চঙ্গ্যা
উত্তর গ হবে
```

দীর্ঘ লেখায় কমা বা দাঁড়ি থাকলে সমস্যা নেই — `প্রশ্ন হবে:` বা `ব্যাখ্যা হবে:` এর পরের পুরো লাইনটাই নেওয়া হয়।

## রাস্তা ৩ — বিস্তারিত বলা, গঠন ছাড়াই

"এই প্রশ্নটা গোলমেলে, জারভিক তো নকশা করেছিলেন, প্রতিস্থাপন করেছিলেন ডিভ্রিস" — এরকম কথা **model-এ যায়**, তাই key আর নেট লাগে। ফিরে আসে একই তালিকা হয়ে।

key না থাকলে এই কথাটুকু থেকে অ্যাপ শুধু সতর্কতাটুকু বসাতে পারবে, সংশোধিত লেখাটা নয় — কারণ আপনি সংশোধিত লেখাটা বলেননি, আর অনুমান করে প্রশ্ন লিখে ফেলা এই অ্যাপ করে না।

## যা কখনো হয় না

- সন্দেহ থেকে উত্তর বদলানো।
- নিজে থেকে প্রশ্ন বা অপশন বানিয়ে ফাঁক ভরাট করা।
- আপনার টিক ছাড়া কিছু সেভ হওয়া।
- নম্বর না মিললে কাছাকাছি কোনো প্রশ্নে বসিয়ে দেওয়া — না মিললে বাদ যায়।
